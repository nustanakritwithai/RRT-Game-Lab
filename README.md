# RRT Arena V0.6.2 — Active Tactical Positioning

[เล่นเกมออนไลน์บน GitHub Pages](https://nustanakritwithai.github.io/RRT-Game-Lab/) · [เปิดโค้ดเกม](./index.html)

เว็บเกม AI แบบใช้กฎ 2 บอต แข่งขันในแผนที่ 2D บนมือถือได้ ไม่มี LLM/API Key

## อัปเดต V0.6.2: เมื่อเห็นศัตรูแล้วต้องมีแผนรุก ไม่ใช่แค่ยืนรอยิง

- บอตคำนวณตัวเลือก **ประมาณ 30–40 ตำแหน่ง** เมื่อเห็นศัตรูจริง โดยเลือกจุดยิงจาก LOS, ระยะยิง, ระยะเดิน, เส้นทางที่อ้อมกำแพงได้, แผนที่จุดที่เคยถูกยิง และประวัติเป้าหมายที่เพิ่งเลือก (จำนวนที่ผ่านตัวกรองอาจน้อยกว่า)
- กลยุทธ์ `orbit/strafe` เลื่อนยิงด้านข้าง, `flank` อ้อมเข้ามุมยิง, `pressure` เข้าใกล้เมื่อไกลเกิน, `kite` ถอยเมื่อใกล้เกิน
- เลือกจุดหมายจากการประเมินที่ตรวจสอบได้ แล้วส่งให้ Memory-Guided RRT หาเส้นทาง ก่อนให้ตัวละครเดินและยิงได้ระหว่างเคลื่อนที่
- เปลี่ยนโหมดใหม่ได้ด้วย **Active Combat Positioning** (เปิดเป็นค่าเริ่มต้น; ปิดเพื่อทดลองกฎ V0.6.1)
- แสดงคะแนน/เหตุผล กลยุทธ์แต่ละฝ่าย และจำนวนการเลือกการเคลื่อนที่แต่ละประเภท
- ข้อมูลศัตรูสำหรับ tactical scoring ต้องมาจาก **สถานะ visible** เท่านั้น หากมองไม่เห็นจะกลับไปใช้ความจำ last seen กับ RRT โดยไม่อ่านตำแหน่งศัตรูปัจจุบันที่ซ่อนอยู่
- ระบบเดิมยังมีการหลบกระสุน ขึ้นกำแพง หาที่กำบัง รีโหลด ปรับ risk และ replay JSON

## โครงสร้างไฟล์

- `index.html` เกมไฟล์เดียว พร้อม JavaScript ฝังครบ ไม่ต้องมี dependency ภายนอก
- `rrt_arena_tactics_v062.js` อัลกอริทึมให้คะแนนตำแหน่งรุก แยกเป็น pure functions
- `rrt_arena_tactics_v062.test.cjs` Unit Tests สำหรับ tactical positioning
- `rrt_arena_guided_v061.*` และ `rrt_arena_memory_v061.*` ยังใช้เพื่อการสุ่ม RRT แบบใช้ข้อมูลและความจำ
- `rrt_arena_v05_core.*` ระบบ cost-aware RRT และการตัดสินใจยุทธวิธีเดิม

## การทดสอบ

รัน `node --test rrt_arena_v05_core.test.cjs rrt_arena_memory_v061.test.cjs rrt_arena_guided_v061.test.cjs rrt_arena_tactics_v062.test.cjs`

ตรวจเบราว์เซอร์ Playwright แยกบน viewport มือถือและเดสก์ท็อป ครอบคลุม: สั่งเห็นศัตรูจริง, คำนวณจุดโจมตี, สลับกลับโหมดเดิม, แก้กำแพงระหว่างดวล, collision validation, รีเพลย์, จบแมตช์, รีเซ็ต และ JavaScript errors

## ข้อจำกัด

- กลยุทธ์เป็น **heuristic / rule-based AI** ไม่ใช่การฝึกโมเดลหรือ Tool Calling ผ่าน LLM
- คะแนนเป็นการประเมินจุดโดยประมาณ ไม่รับประกันว่าการหาทางด้วย RRT จะสำเร็จทุกครั้ง
- ใช้การมองเห็นตาม line-of-sight ของเกม; เซนเซอร์หุ่นยนต์จริงต้องพัฒนาเพิ่ม
- ต้นไม้ RRT ยังต้องสุ่มสำรวจเส้นทางอ้อมได้ จึงไม่ได้ถูกล็อกให้ไปด้านหน้าตลอด
- Replay บันทึกสถานะเป็นช่วง ไม่ใช่ deterministic input playback หรือวิดีโอ
