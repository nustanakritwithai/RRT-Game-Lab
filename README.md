# RRT Arena v0.5 — Tactical AI Battle Lab

[เปิดเกมบน GitHub Pages](https://nustanakritwithai.github.io/RRT-Game-Lab/) · [ดูไฟล์เกม `index.html`](./index.html)

เว็บเกม 2D แบบไฟล์เดียวสำหรับทดลองบอต BLUE และ RED สู้กัน โดยคำนวณเส้นทางด้วย RRT และตัดสินใจทางยุทธวิธีด้วยกฎ JavaScript

## เปิดเล่นบนมือถือ

เล่นออนไลน์ได้ที่ **https://nustanakritwithai.github.io/RRT-Game-Lab/** (หลัง GitHub Pages เผยแพร่สำเร็จ) หรือดาวน์โหลด `index.html` มาเปิดในเบราว์เซอร์ที่รัน JavaScript ได้ เช่น Chrome

กด **เริ่มดวล** เพื่อให้บอตทั้งสองวางแผนและยิงกันอัตโนมัติ กด **หยุด** เพื่อหยุดเกมชั่วคราว หรือ **รีเซ็ตทั้งหมด** เพื่อเริ่มการทดลองใหม่

## สิ่งที่เพิ่มจากเวอร์ชันเดิม

- **Tactical decisions:** BLUE และ RED เลือกเองระหว่างเข้าประชิด อ้อมโจมตี เปลี่ยนมุมยิง ถอย และเข้าที่กำบัง
- **Cover seeking:** ระบบสุ่มตำแหน่งรอบหน้ากำแพงและเลือกเฉพาะตำแหน่งที่มีสิ่งกีดขวางบังการมองเห็นของศัตรู
- **Reload tactics:** รีโหลดเมื่อกระสุนหมดหรือใกล้หมดในจังหวะที่ไม่มีแนวยิง แล้วหาที่กำบังเมื่อเหมาะสม
- **Risk-aware RRT:** ยังคงสุ่มสำรวจด้วย RRT แต่เลือกจุดเชื่อมในบริเวณใกล้เคียงด้วยต้นทุนที่รวมความเสี่ยงจากการมองเห็นของศัตรู (cost-aware local parent selection)
- **Safe smoothing:** ถ้าการตัดทางอ้อมจะเพิ่มความเสี่ยงมาก ระบบจะคงแนวเส้นทางเดิมแทนการย่นระยะ
- **Decision panel:** แสดงเจตนา เหตุผล ระดับความเสี่ยงของเส้นล่าสุด และจำนวนการวางแผนของแต่ละบอต
- **Fair timeout:** เมื่อหมดเวลาและพลังชีวิตสูสีภายในเกณฑ์ จะตัดสินเป็นเสมอ ไม่มอบชัยชนะแบบสุ่ม

## การทดลองสามแบบ

1. ทดลอง Goal Bias 0%, 15%, 40% แล้วสังเกตจำนวนจุด RRT และการค้นหา (ผลมีความสุ่ม ต้องทดลองหลายรอบ)
2. ปรับ **หลีกเลี่ยงเส้นทางเสี่ยง** ระหว่าง 0% และ 100% แล้วสังเกตเส้นทางสีส้มที่เปิดรับศัตรู และเหตุผลการตัดสินใจ
3. เปลี่ยน BLUE เป็นระมัดระวังและ RED เป็นบุกหนัก แล้วใช้ **แตะวางกำแพง** เพิ่มกำแพงระหว่างการต่อสู้ เพื่อดูการวางแผนใหม่

## สถาปัตยกรรม

- Perception (ตำแหน่ง/ระยะ/แนวการมองเห็น) → Tactical Rule Decision → Goal Selection → Risk-aware RRT → Movement & Combat → HUD/Logs
- HTML เป็นไฟล์เดี่ยว มี JavaScript ทั้งหมดอยู่ภายในและไม่ใช้ CDN/API Key/โมเดล AI ภายนอก
- `rrt_arena_v05_core.js` เป็นสำเนาส่วนตรรกะแบบ pure functions ใช้สำหรับ unit test; เกม HTML ไม่จำเป็นต้องโหลดไฟล์ JS แยกนี้
- ส่วน risk-aware RRT **ยังไม่ใช่ RRT\*** เพราะไม่มีการ rewire ต้นไม้ทั้งหมด
- คะแนนความเสี่ยงเป็น heuristic จาก line of sight ไม่ใช่แบบจำลองความน่าจะเป็นที่ถูกยิงจริง
- ยังไม่ต่อ Typhoon/LLM, ยังไม่มีการเรียนรู้ข้ามแมตช์ หรือการมองเห็นที่จำกัดตามเซนเซอร์ของ Agent

## ผลการตรวจสอบ

- `node --test rrt_arena_v05_core.test.cjs` — ผ่าน 9/9 กรณี
- Playwright browser interaction บน viewport มือถือและเดสก์ท็อป — ผ่าน 30/30 กรณี
- จำลองแมตช์เต็ม: มีผู้ชนะและกดเริ่มรอบถัดไปได้
- ตัวตรวจ waypoint/ตำแหน่งผู้เล่นผ่านหลังเพิ่มกำแพง
