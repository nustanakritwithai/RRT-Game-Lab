# RRT Arena V0.6.3 — Dynamic Defense & Stable HUD

[🎮 เล่นออนไลน์บน GitHub Pages](https://nustanakritwithai.github.io/RRT-Game-Lab/) · [โค้ดเกม](./index.html)

สนามทดลอง RRT สองบอตบนเว็บมือถือ รองรับการประเมินการโจมตีและการป้องกันเชิงรุกแบบใช้กฎ **ไม่ใช้ LLM หรือ API Key** ตัวละครใช้ RRT หาเส้นทางเดินจริงและตรวจการชนตลอดทาง

## ใหม่ใน V0.6.3 — รู้ว่าตัวเองน่าจะถูกเห็น ต้องเคลื่อนที่

- **Suspected exposure:** เมื่อบอตมองเห็นฝ่ายตรงข้าม จึงอนุมานอย่างระมัดระวังว่าฝ่ายตรงข้ามอาจเห็นตนเช่นกัน (สมมุติเซนเซอร์ในเกมเท่ากัน) เก็บเวลาที่น่าจะถูกเปิดเผยไว้ชั่วคราว ไม่อ่านความจำหรือข้อมูลลับของศัตรู
- **Defensive relocation:** เมื่อถูกพบและอยู่นิ่งนาน ระบบประเมินตำแหน่งใหม่รอบตัว เน้นหลุดจากแนวยิง แยกจากจุดเสี่ยงและจุดที่เพิ่งเคยใช้ แต่ยังยอมอ้อมกำแพงด้วย Memory-Guided RRT
- **Stay mobile without thrashing:** ไม่ยกเลิกเส้นทางที่กำลังเดินทุกเฟรม หลีกเลี่ยงการเลือกจุดเดิมซ้ำ และอนุญาตให้หยุดยิงชั่วคราวเมื่อตนได้เปรียบชัดเจน ก่อนบังคับประเมินใหม่
- **Under-fire awareness:** เมื่อถูกยิงหรือกำลังรีโหลด ระบบให้ความสำคัญกับการเคลื่อนตัวมากขึ้น
- **เปรียบเทียบได้:** เปิด/ปิด `Dynamic Defense` ในหน้าเกม และดูสถิติ “การย้ายเมื่อถูกพบ / หลุดแนวยิง”
- **Stable mobile HUD:** การ์ด BLUE/RED สูงคงที่, สถานะหนึ่งบรรทัดพร้อม ellipsis และชื่อเต็มในแผงรายละเอียด ทำให้ข้อความไม่ดันสนามลงขึ้นเอง (หน้าจอ 320px, 393px, desktop)

## เล่นและทดลอง

1. เปิดเกม กด **เริ่มดวล** ลองเลือกแผนที่ `ลานโล่ง` เพื่อให้บอตมองเห็นกันบ่อยขึ้น
2. เปิด `Dynamic Defense` สังเกตการย้ายตำแหน่งหลังถูกพบ และดูแผง “สิ่งที่บอตกำลังคิด”
3. ปิด `Dynamic Defense` เพื่อเปรียบเทียบกับกลยุทธ์ Active Combat Positioning ที่มีอยู่แล้ว
4. เปิด `Memory-Guided RRT` และทดลองวางกำแพงระหว่างการต่อสู้เพื่อดูเส้นทางที่คำนวณใหม่

## ระบบและหลักความถูกต้อง

- `index.html`: HTML/JavaScript ฝังครบ เล่นออฟไลน์ได้
- `rrt_arena_defense_v063.js`: pure functions — `assess(observation)` ประเมินความจำเป็นต้องย้าย, `plan(observation)` ให้คะแนนจุดป้องกัน แล้วส่งเป้าหมายให้ RRT
- `rrt_arena_defense_v063.test.cjs`: Unit Tests เพิ่ม 18 กรณี
- `rrt_arena_tactics_v062.*`: เลือกตำแหน่งโจมตีแบบรุก (คงระบบเดิม)
- `rrt_arena_guided_v061.*`: Memory-Guided RRT
- `rrt_arena_memory_v061.*`: ความจำตำแหน่งศัตรูที่เคยเห็นและจุดเสี่ยง
- `rrt_arena_v05_core.*`: การประเมินเส้นทาง การตรวจการชน และกฎยุทธวิธีพื้นฐาน

ตัวประเมิน `Dynamic Defense` ใช้เพียงข้อมูลที่บอตรับรู้หรือจำได้ แต่ **ไม่ได้ยืนยันว่าศัตรูรู้ตำแหน่งจริงทุกครั้ง** เพราะยังไม่มีระบบจำลองระดับการรับรู้ของศัตรูแบบมีความไม่แน่นอนเต็มรูปแบบ

## การทดสอบ

- `node --test *.test.cjs` — ผ่าน 63/63
- Playwright headless Chromium (320px, 393px และ 1365px) — ผ่าน 45/45
- ตรวจ layout เมื่อข้อความสถานะยาว การเคลื่อนที่หลังถูกพบ ความปลอดภัยเส้นทาง การปิดระบบป้องกันเพื่อเปรียบเทียบ และ JavaScript runtime errors

## ข้อจำกัดและแนวทางต่อยอด

- AI ยังเป็น **rule-based / heuristic** ไม่ได้เชื่อม LLM หรือเรียนรู้โมเดลใหม่
- อัลกอริทึมประมาณคุณภาพตำแหน่ง ไม่รับประกันตำแหน่งเหมาะสมสูงสุดหรือมีเส้นทางถึงทุกครั้ง
- เมื่อคู่ต่อสู้หลุดสายตา ใช้ข้อมูลที่เคยเห็น ไม่ใช่ตำแหน่งจริงที่อัปเดตจากการมองไม่เห็น
- ขั้นต่อไป: เปรียบเทียบสถิติความได้เปรียบระหว่าง Dynamic Defense เปิด/ปิด และเพิ่ม route cache ที่ตรวจสอบสิ่งกีดขวางใหม่ได้
