# ธงศึก: เจ้าแคว้น — WARLORD V0.2

เกมต้นแบบสงครามบนเว็บมือถือแนว Mount & Blade (มุมมอง 2D)

- เริ่มต้นจากแม่ทัพหนึ่งคน เดินทางตามแผนที่
- จ้างทหารในเมือง: ทหารราบ พลธนู และทหารม้า
- ควบคุมกลุ่มทหารแยกประเภทได้ระหว่างการรบ: ตามแม่ทัพ / ตั้งรับ / บุก
- เปลี่ยนรูปขบวน: แนวแถว / หัวลูกศร / แถวตอน
- โจมตีและยึดป้อม พร้อมบันทึกความคืบหน้าในเบราว์เซอร์

เปิดเกมผ่านไฟล์ [index.html](./index.html) หรือ GitHub Pages เมื่อ deploy สำเร็จ:
