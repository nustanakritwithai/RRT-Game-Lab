เมื่อ Agent เบาบางและสัญญาณสั้น อาจไม่มีเส้นทางถึงกัน โปรโตคอลไม่สามารถส่งทะลุระยะวิทยุได้ หากเปิดเคลื่อนที่ Agent จะถือข่าวไปรอพบเพื่อนใหม่ ระบบ Adaptive ส่งข่าวลืออย่างจำกัด ให้รายงานสำรวจมีลำดับสูง และเช็กข้อมูลที่ขาดเป็นระยะ
ข้อจำกัด ผลคือการจำลอง Agent แบบมีกฎ ไม่ใช่ LLM จริง การ ACK ไม่รับประกันการส่งถึงตลอดเวลา และการส่งซ้ำมีเพดาน ไม่มีการยืนยันตัวตนทางคริปโต ส่วนผล “พบ/ไม่พบ” มาจากเซนเซอร์ซื่อสัตย์ในโลกจำลองเท่านั้น
