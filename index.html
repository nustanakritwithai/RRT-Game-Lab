ต่างจาก LLM อย่างไร?

ตัวอย่างนี้ใช้ กฎยุทธวิธี + Risk-aware RRT ไม่มีโมเดลภาษาและไม่ใช้ API Key. บอตจะประเมิน 30–40 จุดยิงจากมุมมองของตัวเองเมื่อเห็นศัตรู เลือกจุดที่มีแนวยิงเหมาะสมและไม่ซ้ำจุดเดิม แล้วยังคงใช้ Memory-Guided RRT วางเส้นทางจริง บอตรับรู้ตำแหน่งศัตรูที่มองเห็นและบันทึกตำแหน่งที่เคยพบ (ไม่รู้ตำแหน่งจริงเมื่อถูกบัง) RRT ใช้ความจำและแนวเส้นทางเพิ่มน้ำหนักพื้นที่ค้นหา แต่ยังสุ่มทั่วสนามบางส่วน จุดเสี่ยงเกิดจากที่เคยถูกยิง ไม่ใช่การฝึก ML. Replay เป็นภาพสถานะที่บันทึกเป็นช่วง ไม่ใช่วิดีโอหรือการเล่นแบบ deterministic. LLM Tool Calling คือขั้นต่อไป

ทดลอง: เปรียบเทียบ Memory-Guided 0% กับ 85% → ดูการกระจายกิ่ง RRT → ดูสถานะการมองเห็น → วางกำแพงบังศัตรู → ดูการค้นหาจากความจำ → ดูความเสี่ยงจากจุดที่เคยถูกยิง → เล่น Replay หลังจบแมตช์ • ทุกอย่างทำงานในเบราว์เซอร์
